# Геоинформационная система оценки обеспеченности социальной инфраструктурой

Тема проекта: **«Разработка геоинформационной системы оценки обеспеченности урбанизированной территории объектами социальной инфраструктуры»**.

## Что уже реализовано

- авторизация без публичной регистрации;
- единая локальная учётная запись, создаваемая при запуске;
- PostgreSQL + PostGIS;
- интерактивная подложка OpenStreetMap;
- категории социальных объектов на русском языке;
- выбор произвольной точки на карте;
- поиск ближайшего объекта каждой категории;
- сравнение с нормативным расстоянием;
- цветные линии от анализируемой точки до объектов;
- поддержка геометрии объекта;
- модели дорожного графа OSM;
- импорт дорог и социальных объектов из OSM PBF;
- расчёт пешеходного маршрута по локальному графу после его импорта.

## Локальный запуск

```bash
git pull
bash start-local.sh
```

Для локальной проверки автоматически создаётся единая учётная запись: логин **pavel**, пароль **12345678**. В рабочем окружении эти тестовые данные должны быть заменены.

После запуска:

- сайт: http://localhost:5173
- API: http://localhost:8000/api
- админ-панель: http://localhost:8000/admin

## OSM-подложка

Для интерактивного просмотра используется стандартная растровая подложка OpenStreetMap с обязательной атрибуцией.

Подложка нужна только для отображения карты. Она не скачивается целиком и не используется для построения графа.

## Дорожный граф и социальные объекты OSM

Для маршрутизации используется отдельный импорт исходных данных OSM в локальную PostgreSQL/PostGIS.

Запуск:

```bash
bash import-tyumen-osm.sh
```

Команда скачивает актуальный PBF Уральского федерального округа с Geofabrik и импортирует в БД дорожные сегменты и социальные объекты в пределах картографического охвата Тюменской области.

Исходный PBF имеет большой размер, поэтому он не хранится в Git и сохраняется локально в `data/osm/`.

После импорта при анализе точки расстояние рассчитывается по пешеходному графу OSM. Пока граф не импортирован, интерфейс явно показывает временный расчёт по прямой пунктирной линией.

## Категории OSM

На текущем этапе автоматически распознаются:

- школы;
- детские сады;
- поликлиники и врачебные учреждения;
- больницы;
- магазины;
- остановки общественного транспорта;
- спортивные объекты;
- аптеки;
- библиотеки, театры, кинотеатры, музеи и другие объекты культуры;
- объекты социального обслуживания.

- PostgreSQL + PostGIS
- PyOsmium
- Docker Compose

## Важно для публичного размещения

Перед публикацией необходимо заменить локальный пароль, `DJANGO_SECRET_KEY`, настроить HTTPS и использовать подходящий production-провайдер картографических тайлов либо собственный тайловый сервис.

Данные OpenStreetMap используются с указанием авторства OpenStreetMap contributors.
