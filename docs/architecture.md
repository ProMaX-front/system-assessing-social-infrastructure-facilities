# Архитектура MVP

## Компоненты

- **Frontend** — React + TypeScript + MapLibre GL JS.
- **Backend** — Django REST Framework + GeoDjango.
- **Database** — PostgreSQL + PostGIS.
- **Authorization** — JWT.
- **Local environment** — Docker Compose.

## Основные сущности

### AdministrativeUnit

Иерархия административно-территориальных единиц: страна → субъект → муниципалитет → населённый пункт → район → микрорайон → квартал.

### SocialObject

Объект социальной инфраструктуры с категорией, координатой, адресом, мощностью и источником данных.

### Normative

Норматив доступности/обеспеченности, связанный с категорией объекта и, при необходимости, территорией применения.

## Анализ точки

MVP принимает координату пользователя, для каждой категории находит ближайший объект и сравнивает расстояние с применимым нормативом.

На текущем этапе применяется геодезическое расстояние PostGIS. В следующей итерации расчёт будет заменён на кратчайший пешеходный путь по графу улично-дорожной сети.

## Следующие подсистемы

- ETL официальных и открытых геоданных;
- маршрутизация;
- нормативный движок с приоритетами федеральный → региональный → местный;
- расчёт охвата населения;
- расчёт мощности/дефицита;
- интегральный индекс обеспеченности;
- тематические слои по административным единицам.
